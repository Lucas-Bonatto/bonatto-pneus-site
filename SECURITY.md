# Política de segurança

## Versões mantidas

A versão publicada na branch `main` recebe correções de segurança.

## Como relatar uma vulnerabilidade

Não publique detalhes sensíveis em uma issue aberta. Envie a descrição, os passos
para reprodução e o impacto observado para `bonatto@bonattopneus.com.br`.

Evite acessar, alterar ou copiar dados que não sejam seus durante a pesquisa.
Responderemos assim que possível e trataremos o relato de forma responsável.
